BOSS 直聘 · 批量投递助手

v1.12.0 Chrome 扩展 / MV3 解压即用 · 无需安装 网吧 / 公共电脑使用说明

这个包里只有扩展本体和这份说明，没有测试文件、源码工程文件或任何个人数据。 第一次使用请按顺序做一遍，尤其别跳过第 6 步「离机前清理」。

⚠ 这是公共电脑，先把这三条记住
  1. 不要填 AI API Key（默认是关的，保持关闭）——填了就等于把密钥留在网吧电脑里。
  2. 不要让浏览器记住 BOSS 账号密码，登录时取消「记住我」「保存密码」。
  3. 走之前必须导出记录并移除扩展，见第 6 步的勾清单。网吧可能有还原卡，也可能没有，别赌。

0 出发前：把这个包带上

压缩包 boss-auto-apply-v1.12.0-网吧便携版.zip 传到你能下载的地方：

  • U 盘 / 移动硬盘（最稳，也方便把投递记录带回来）
  • 网盘、微信「文件传输助手」、自己的邮箱附件（不要发到公共群）

包里没有 exe，不会触发网吧的安全软件；只是一个 zip + 一个文件夹。

建议：先在自己电脑上按第 2–4 步试一遍，确认面板能弹出来、筛选条件填对了，再去网吧直接用。省得在计时收费的机器上调试。

1 在网吧解压

  1. 下载 zip，右键 → 全部解压（Windows 自带即可，不需要 WinRAR）。
  2. 解压到一个好找的目录，例如 D:\boss-auto-apply\。
  3. 打开后应该能看到 manifest.json、content\、background\、popup\、records\ 和这份说明。
网吧还原卡：很多网吧重启后会清掉 D 盘新文件。这其实是好事（隐私自动没了），但意味着每次上机都要重新解压，而且这台机器上不会保留你上次的配置和投递记录。所以每次都要把记录导出带走。

要加载的是包含 manifest.json 的那一层文件夹，不是 zip 本身，也不是它的上一层。

2 装进 Chrome（不用商店、不用登录）

  1. 打开 Chrome，地址栏输入 chrome://extensions 回车。
  2. 右上角打开 开发者模式 开关。
  3. 点左上角 加载已解压的扩展程序。
  4. 选中第 1 步解压出来的文件夹（里面直接能看到 manifest.json），点「选择文件夹」。
  5. 卡片出现、版本号显示 1.12.0 即成功。Edge 用 edge://extensions，步骤一样。
如果提示「程序包无效」或清单报错：多半是选错了层级（选到了 zip 或外层文件夹）。回到第 1 步确认目录里直接有 manifest.json。
如果开发者模式是灰的：这台机器被管理策略锁了，换一台机器或用便携版 Chrome。

刷新已经打开的 BOSS 页面，右下角出现青色圆形「投」按钮就对了。不刷新不会注入。

3 登录与配置

  1. 打开 BOSS 直聘网页版并登录。取消「记住我」「保存密码」。
  2. 先在 BOSS 自己的搜索框里粗筛一次（城市、岗位关键词），插件只在你当前这个列表页里工作。
  3. 点右下角「投」展开面板，按需填写：
    项目建议
    期望城市只填一个，例如 杭州；这是硬条件，写错会全被跳过
    薪资 / 公司规模 / 融资 / 发布时间不确定就留空或关掉，别叠太多条件
    专业直接写你的专业，例如「计算机相关」；JD 明确限专业且对不上会跳过
    编程语言勾你真正会的；没勾的不要硬投
    证书有就勾上，否则「必须持有 XX 证」的岗位会被拦
    关键词「必含词」默认关；投不出去时先检查是不是被它卡住
    每次上限 / 间隔网吧建议先 30 份、间隔保持 8–15 秒，别一上来跑满 150
    AI 语义判断保持关闭。公共电脑上不要填任何 API Key
  4. 网慢的话把「详情等待」「滚动等待」「JD 每步等待」调大一点，插件要等右侧详情真正切成当前岗位才会判断。

4 先试跑，再正式投

  1. 勾演练模式（只列名单不点击）跑一小段，看面板「跳过原因统计」是不是符合预期。
  2. 确认没有「一个也投不出去」或「投了别的城市」之后，关掉演练模式。
  3. 点开始投递。它会自己逐个点开岗位卡片、滚动读完 JD、以「去APP与BOSS随时沟通」为截止判断，然后点「立即沟通」。
  4. 随时可以按 ESC 或面板按钮中断。
正常表现：日志里能看到当前岗位名、读到的 JD 长度、跳过原因；投完会自动点掉「留在此页」弹窗，继续下一张卡。如果一直停在同一个岗位，把等待时间调大。

5 把记录带走

  1. 点扩展弹窗或面板里的投递记录，打开记录表。
  2. 点导出 CSV，保存到 U 盘 / 你自己的网盘，不要留在网吧硬盘上。
  3. 文件名建议带日期，例如 投递记录-2026-11-12.csv。CSV 带 BOM，Excel / WPS 直接打开不乱码。

记录里有你投过的公司和岗位，属于个人数据。导出后本机那份就没用了。

6 离机前清理（逐项勾）

别直接下机走人。扩展的配置和投递记录存在这个 Chrome 用户配置文件里，没有还原卡的机器会一直留着。

常见问题

现象怎么办
右下角没有「投」按钮装完扩展后刷新 BOSS 页面；确认当前网址是 zhipin.com；确认扩展卡片没被停用
一个也投不出去看面板「跳过原因统计」，哪个原因最多就先关掉对应的硬条件（常见：城市写错、专业填太窄、必含词被打开、最低分太高）
一直提示找不到沟通按钮网慢导致详情没切完，把「详情等待」「滚动等待」调大；确认不是只滚不点
薪资显示方框 / 「薪资加密」BOSS 的字体加密，插件会尽量还原；还原不了会明写「薪资加密」，不影响其它条件判断
改了配置没生效面板配置是即时保存的；如果改的是 manifest.json，必须回 chrome://extensions 点「重新加载」再刷新页面
投完弹窗卡住插件会自动点「留在此页」；若 BOSS 改了弹窗文案，先手动关掉弹窗再继续
网吧 Chrome 版本很老MV3 扩展需要 Chrome 88+；太老就换台机器或用便携版 Chrome

这个包里有什么

boss-auto-apply/
├── manifest.json          扩展清单（Chrome MV3）
├── 使用说明.html          本文件，双击即可看
├── 使用说明.md            纯文字版
├── MANIFEST.txt           文件清单 + 校验值
├── LICENSE                MIT 许可证
├── background/            后台：记录、去重、可选 AI 代理
├── content/               面板 + 筛选引擎 + 页面数据桥
├── popup/                 点扩展图标的小窗
└── records/               投递记录表与 CSV 导出

测试文件、回归断言、分层排障文档、CI 配置都在 GitHub 仓库里，这个便携包不含它们——网吧用不上，也不该把工程文件带来带去。
